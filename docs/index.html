Características

Todo lo que necesitas
para un reporte profesional

Diseñado por pentesters para pentesters. Cada función está pensada para acelerar la documentación sin sacrificar calidad.

📋

Plantillas predefinidas

Más de 20 plantillas para las vulnerabilidades más comunes: SQLi, XSS, RCE, IDOR, SSRF, Path Traversal, JWT Bypass, WordPress y muchas más.

📊

CVSS · CWE · CVE

Asigna puntuaciones CVSS, mapea las vulnerabilidades a MITRE CWE y referencia CVEs. El resumen estadístico se genera automáticamente.

🎨

Temas Light / Dark / HTB

Tres temas visuales para el informe final. El tema HackTheBox está diseñado fielmente sobre la paleta oficial de HTB, ideal para certificaciones CPTS/CBBH.

📄

Exportación a PDF

Genera el informe directamente desde el navegador. El PDF mantiene el tema activo — fondo oscuro, colores y tipografía incluidos.

🔒

Clasificación TLP 2.0

Incluye el sistema de clasificación Traffic Light Protocol en versión 2.0. Marca cada informe con TLP:WHITE, GREEN, AMBER o RED.

📸

Evidencias con capturas

Adjunta screenshots de evidencia por hallazgo mediante drag-and-drop, carga de archivo o pegado directo con Ctrl+V.

💾

Autoguardado persistente

Los datos se guardan automáticamente en SQLite 2 segundos después de cada cambio. Importa y exporta la base de datos completa en un clic.

🌐

Español e Inglés

Toda la interfaz y los informes generados pueden cambiarse entre español e inglés en cualquier momento desde el menú de ajustes.

🐳

Despliegue con Docker

Un solo docker run y la herramienta está lista. La imagen incluye Playwright para la generación de PDFs desde el servidor.

Instalación

En marcha en menos
de 60 segundos

Docker es la forma recomendada. La imagen incluye todas las dependencias, incluido Playwright para la generación de PDFs en servidor.

Terminal
# 1. Clonar el repositorio
git clone https://github.com/ccyl13/Pentestify.git
cd Pentestify

# 2. Construir la imagen
docker build -t pentestify:latest .

# 3. Ejecutar el contenedor
docker run -d \
  -p 8000:8000 \
  -v pentestify_data:/app/data \
  --name pentestify \
  pentestify:latest

# ✅ Abre: http://localhost:8000
Terminal
# 1. Clonar el repositorio
git clone https://github.com/ccyl13/Pentestify.git
cd Pentestify

# 2. Crear entorno virtual e instalar dependencias
python3 -m venv venv
source venv/bin/activate # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Instalar Playwright (para exportar PDF desde servidor)
playwright install chromium

# 4. Arrancar
python3 run.py

# ✅ Abre: http://localhost:8000
